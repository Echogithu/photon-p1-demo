# Photon P1 Demo V1.0 · Echogithu

非官方产品原理与任务工作流教学模拟。该仓库保存可直接部署的独立 HTML、原创分享图和第三方许可。

## 在线体验

GitHub Pages 目标地址：https://echogithu.github.io/photon-p1-demo/ 。是否已启用以仓库 Settings → Pages 和实际 HTTPS 访问结果为准。

## 本地体验

直接用桌面浏览器打开 index.html，无需安装依赖或运行服务器。CSS、SVG 与运行脚本都内嵌在页面中，可查看 HTML 源码。

## 交互

- LCD 掩模、曝光、Z 轴升降与逐层成形；单槽与选配双材料套件示意。
- 准备 → 教学切片 → 检查/修复/复查 → 打印监控 → 后处理。
- 快速 12× / 完整 3× 共用状态机；默认两项异常，修复后必须复查。
- 参数变化使旧切片和预检失效；暂停、恢复、重置与原理动画同步。
- 窄屏、深浅色和键盘操作。此前 Chrome 桌面及 320/375/390px 已验证。

## 发布与更新

仓库 Settings → Pages → Deploy from a branch → main / (root)。无需自有域名。
更新时修改已有源项目、构建并验证，再替换该仓库对应静态文件后提交；Pages 自动重新发布。
迁移只修改站点元信息和作品仓库链接，内嵌运行脚本与已验收 V1.0 一致。

## 演示边界

本作品与 Anycubic 无隶属或官方背书关系。双材料属于选配套件。预设截面不代表任意 STL 切片；连接、余量、温度、检查、打印参数和监控均为教学模拟，不提供真实设备 API、实机控制或真实耗时预测。模拟时间不等于实际打印时间。
